# How to request software installation

**Applies to:** any app or license not already on your work computer
**Keywords:** install software, new app, license, download, admin rights, approval

## What you need to know
- For security and licensing reasons, employees **can't install software themselves**. IT installs approved software for you.
- **Every software request needs manager approval.** It goes to your approver automatically; you don't need to email them.
- Personal-use apps (games, streaming, personal subscriptions) **aren't approved** for work devices.

## Steps
1. Check whether the app is already available. Look in the **Start menu** or the company software center first.
2. Go to the portal: **Request something → Request software installation**.
3. In **"What do you need, and why?"**, include:
   - the exact app name and version (or a link)
   - the **business reason** (what work it helps you do)
   - whether it needs a **paid license**
4. Submit. Your request shows **Waiting for approval** until your manager decides.

## What happens next
- **Approved:** IT schedules the install and may ask when your computer is available.
- **Declined:** the request is closed with resolution **Declined**. You can submit a **new** request with a stronger business reason. Comments on a declined request won't reopen it.

## Verify it worked
- The app opens from your Start menu and you can sign in or activate it.

## When to contact IT
Comment on your request if it's been **Waiting for approval** for more than 2 business days, or if the installed app doesn't work.
